## PRODUCTION NOTES

- **Audio:** Use a trending lo-fi or chill hop beat as background. Keep vocals clear.
- **Pacing:** Fast cuts every 3-4 seconds to maintain engagement.
- **Text overlays:** Use bold, clean font. Key phrases: "AI VIBE MATCH", "40+ COUNTRIES", "FREE PREMIUM".
- **Screen recordings:** Record in dark mode for visual appeal. Use phone mockup frames.
- **Tone:** Casual, authentic, slightly nerdy about music. Not salesy.
- **End screen:** Link in bio + code reminder.
